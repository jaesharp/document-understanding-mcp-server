# Document Understanding MCP Server: Future Plans

This directory contains planning documents for future development of the Document Understanding MCP Server. These documents outline proposed changes, enhancements, and architectural evolutions.

## 🚀 Upcoming Major Changes

> **IMPORTANT**: The Document Understanding MCP Server is planning a significant architectural evolution to support multiple document types beyond PDF. This will involve changes to the API interface, moving to a document handle-based approach. See [multi_document_type_support.md](multi_document_type_support.md) for details.

## Available Plans

| Plan | Description | Status |
|------|-------------|--------|
| [PDF Testing Transition Plan](pdf_testing_transition_plan.md) | Transition from static PDF files to dynamically generated PDFs for testing | ⏳ Partially Completed |
| [Multi-Document Type Support](multi_document_type_support.md) | Evolution of the server to support multiple document types beyond PDF | 📋 Planned for 2025-2026 |
| [Publishing Todo Plan](publishing_todo_plan.md) | Tasks to complete before publishing the Document Understanding MCP Server | 🔄 In Progress |

## Contributing to Plans

If you have ideas for future enhancements or architectural changes, please consider contributing to the planning process:

1. Discuss your ideas in an issue first
2. Create a new plan document following the existing format
3. Add your plan to this index
4. Submit a pull request for review

Plans should include:
- Clear problem statement or opportunity
- Proposed solution with technical details
- Implementation considerations
- Migration strategy (if applicable)
- Timeline estimates
